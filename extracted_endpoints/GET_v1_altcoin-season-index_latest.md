# GET /v1/altcoin-season-index/latest

**Summary:** Altcoin Season Index Latest

**Description:** Returns the latest Altcoin Season Index snapshot with yearly high/low statistics. Index scale 0-100; values above 75 suggest altcoin season, below 25 suggest Bitcoin season.

**Cache / Update frequency:** Every 15 minutes.
**Plan credit use:** 1 API call credit per request.

### Parameters

- **X-CMC_PRO_API_KEY** (header) - *Required*: Your CoinMarketCap Pro API key
