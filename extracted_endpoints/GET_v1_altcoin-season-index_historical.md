# GET /v1/altcoin-season-index/historical

**Summary:** Altcoin Season Index Historical

**Description:** Returns historical Altcoin Season Index data for a specified timeframe (7d, 30d, or 90d). Data points are sorted by timestamp (oldest first).

**Cache / Update frequency:** Every 15 minutes.
**Plan credit use:** 1 API call credit per request.

### Parameters

- **X-CMC_PRO_API_KEY** (header) - *Required*: Your CoinMarketCap Pro API key
- **timeframe** (query) - *Optional*: Timeframe for historical data. Valid values are 7d, 30d, and 90d. Default is 7d.
