# GET /v1/tools/postman

**Summary:** Postman Conversion v1

**Description:** Convert APIs into postman format. You can reference the operation from [this article](https://coinmarketcap.com/alexandria/article/register-for-coinmarketcap-api).
  
  
  **This endpoint is available on the following [API plans](https://coinmarketcap.com/api/pricing/):**
  - Free
  - Hobbyist
  - Startup
  - Standard
  - Professional
  - Enterprise

  **Technical Notes**
  - Set the env variables in the postman: {{baseUrl}}, {{API_KEY}}


### Parameters

- **X-CMC_PRO_API_KEY** (header) - *Required*: Your CoinMarketCap Pro API key
