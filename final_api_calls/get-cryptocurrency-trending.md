get-cryptocurrency-trending
URL: https://pro-api.coinmarketcap.com/v1/cryptocurrency/{id}/trending/latest
Description: Get the latest trending data for a specific cryptocurrency.
Parameters:
  - id (string): The ID of the cryptocurrency to retrieve.
    CURL Example: `curl 'https://pro-api.coinmarketcap.com/v1/cryptocurrency/12345/trending/latest'`
    JSON Response Example: `{ "data": { ... } }`
