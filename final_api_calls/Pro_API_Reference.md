Pro API reference endpoint is used to get information about the pro API's cryptocurrency and exchange data.

    - GET /pro-api-reference/cryptocurrency
        Returns a list of all the available cryptocurrencies.
    
    - GET /pro-api-reference/exchange
        Returns a list of all the available exchanges.
    
    - GET /pro-api-reference/global-metrics
        Returns a list of global metrics for cryptocurrency and exchange data.
