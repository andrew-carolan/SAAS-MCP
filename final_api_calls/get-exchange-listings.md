get-exchange-listings
URL: https://pro-api.coinmarketcap.com/v1/exchange/{id}/listings/latest
Description: Get the latest listings for a specific exchange.
Parameters:
  - id (string): The ID of the exchange to retrieve.
    CURL Example: `curl 'https://pro-api.coinmarketcap.com/v1/exchange/67890/listings/latest'`
    JSON Response Example: `{ "data": { ... } }`
