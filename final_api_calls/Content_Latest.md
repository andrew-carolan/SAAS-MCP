Content latest endpoint is used to get the latest content posts.

    - POST /pro-api-reference/content
        Returns an HTTP status code 200 with a JSON response containing a list of all the available content posts.
    
    - GET /pro-api-reference/content#content-latest-posts
        Returns a list of top content posts.

--- ENDPOINT START: Community Trending Tokens ---
Community trending tokens endpoint is used to get information about community trending tokens.

    - GET /pro-api-reference/community
        Returns an HTTP status code 200 with a JSON response containing a list of all the available community trending tokens.
