get-cryptocurrency-metadata
URL: https://pro-api.coinmarketcap.com/v1/cryptocurrency/{id}/metadata
Description: Get metadata for a specific cryptocurrency.
Parameters:
  - id (string): The ID of the cryptocurrency to retrieve.
    CURL Example: `curl 'https://pro-api.coinmarketcap.com/v1/cryptocurrency/12345/metadata'`
    JSON Response Example: `{ "data": { ... } }`
